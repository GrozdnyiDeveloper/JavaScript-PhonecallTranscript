# Файлы отображения транскрипции звонка на форме
В данном репозитории представлены примеры HTML и JS файлов по реализации кастомного отображения транскрипции звонка на форме сущности Звонок среды Dynamics 365. 

**Архив имеет следующее содержимое:**
- callstranscriptions.html - Файл HTML, содержащий отображение транскрипции звонка
- phonecall.js - Файл JS, содержит логику работы формы сущности Звонок, включая метод передачи данных на верстку callstranscriptions.html
